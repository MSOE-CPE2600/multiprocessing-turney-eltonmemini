# What is Mandelbrot?
    The Mandelbrot set is a famous fractal image and a mathematical set of complex numbers. Its complex and beautiful structures are generated by iterating a simple equation, and the resulting patterns can be explored infinitely by zooming in. The set was first visualized by mathematician Benoît Mandelbrot around 1980.
Our program finds approximations of the Mandelbrot around the coordinates -0.761574, -0.0847596. 50 different pictures are created 
as the program zooms in to create a movie.

# Looking at our performance
While increasing the number of processes did greatly increase our performance, using more than our amount of actual processors showed 
to be ineffective with increasing our performance. Increasing the amount of threads we use also improved our performance, but looking at our table there is a sweet spot of around 10 process, 20 threads. Changing the variables to higher numbers didn't show improved performance.
